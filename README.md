Catalogo OMNILIFE + SEYTU (sitio: omnilife-seytu.netlify.app)
- index.html: sitio completo, listo para subir a Netlify (Deploys > browse files to upload).
- catalogo-netlify.zip: el mismo index.html comprimido.
- template.html: fuente editable (precios, textos). Los precios estan en la lista "var P=[...]", penultimo valor numerico de cada fila.
- fotos/: respaldo de las 98 fotos (000.jpg = primer producto).
Para cambiar precios: pedirle a Claude "actualiza los precios" con la lista nueva, y volver a subir el zip.
